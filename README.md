# Object-Oriented Software Design Heuristics

Foundational context for designing and writing software with objects. Each document defines a set
of concepts and principles, written so they can be used directly as context for development. Every
document ends with its sources.

Documents are split by language into separate folders: [`docs/en`](docs/en) (primary, English) and
[`docs/es`](docs/es) (Spanish).

## Structure of each document

1. **Working definition** — the concept stated as a usable definition.
2. **Core definitions** — the building blocks.
3. **Principles for development** — actionable rules to apply while designing and coding.
4. **Glossary** — quick reference.
5. **Sources** — references, at the end.
